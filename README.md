## 🚀 Objetivo

Praticar a construção de formulários modernos e acessíveis, aplicando conceitos importantes do desenvolvimento front-end — desde a estruturação semântica até a experiência do usuário.

---

## 🛠️ Tecnologias utilizadas

| Tecnologia | Função |
|---|---|
| **HTML5** | Estrutura semântica do formulário |
| **CSS3** | Estilização e organização visual |
| **Git e GitHub** | Versionamento de código |

---

## 📚 O que foi aplicado

**Tipos de input:**
- `text`, `email`, `checkbox`, `radio`, `select`

**Estruturação semântica:**
- `fieldset`, `legend`, `label`

**Outros elementos:**
- `textarea` para campos de texto maiores

**Boas práticas:**
- Acessibilidade (rótulos associados, agrupamento lógico de campos)
- Organização visual com CSS
- Versionamento com Git (branches, commits e merge)

---

## 🎯 Funcionalidades

- Formulário organizado e intuitivo
- Melhor experiência para o usuário
- Estrutura pensada para leitores de tela e navegação por teclado

---

## 🧠 O que aprendi com este projeto

- Como estruturar formulários acessíveis usando as tags semânticas corretas
- Boas práticas de organização de inputs e agrupamento de campos relacionados
- Fluxo de versionamento de código com Git (branches, commits e merge)
